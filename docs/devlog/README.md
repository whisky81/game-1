# Devlog

Mỗi tuần một file: `YYYY-Www.md` (ví dụ `2026-W37.md`), tạo từ [../templates/devlog-template.md](../templates/devlog-template.md).

Viết vào 30 phút Chủ Nhật hằng tuần — xem [../02-workflow.md](../02-workflow.md) §2.

Hai file đặc biệt:
- `idea-icebox.md` — mọi ý tưởng mới nảy ra giữa dự án đều ném vào đây, **không làm ngay**
- `bug-icebox.md` — bug không chặn tiến độ, gom lại xử lý theo đợt
